Tempo

A Mac-native event hub. One Mac-native timeline for everything your stack does — from rack-side monitoring to Mac-side automations, from third-party services to your own scripts. If it can POST, Tempo can hear it. Every event arrives in context, with the next move one click away. You stay the conductor; Tempo holds the score — and never acts on its own.

macOS 15+ · Signed + notarized DMG · No App Store · Auto-updates via Sparkle

Download DMG Read the blog

Or install via Homebrew 
brew tap caereforge/tap
brew install --cask tempo

Same signed + notarized DMG, distributed through a public Homebrew tap. Updates flow through Sparkle as usual; brew upgrade --cask tempo works too if you prefer the Homebrew flow. Tap source: github.com/caereforge/homebrew-tap.

Scores

Small declarative JSON files that teach Tempo about a source — the color, the severity rules, and the one-click actions to attach. Drop one in, the source is wired up.

Tempo ships with a core set bundled in. The catalog below adds downloadable extras for tools the bundle doesn't cover.

Utilities

Shortcuts, scripts, and small helper tools that complement Tempo. They don't define a Tempo source — they fit alongside, filling the workflow gaps that the app itself doesn't try to solve.

First entry: a macOS Shortcut to copy message:// deep links from Apple Mail. More land as the catalog grows.
