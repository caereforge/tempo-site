Scores

Small declarative files that teach Tempo how to read events from a specific source and which one-click actions to attach. Drop one into Tempo, and the source is wired up.

Tempo v1 ships with several scores built-in — they don't need to be downloaded, just configured. Apple Calendar and Reminders are first-class sources too, surfaced via a dedicated EventKit integration. The other entries here are downloadable add-ons for sources outside the bundled set, with the catalog growing over time.

Score installed but nothing lands in the feed? See troubleshooting networking — five patterns cover almost every case.

Hazel

Bring Hazel rule fires into your Tempo timeline. Each rule firing becomes an event with one-click actions to open the file, jump to the source or destination folder, and copy the path or rule name.

v1.0.0 · Hazel 5 / Hazel 6

Home Assistant

Available with Tempo v1

Home Assistant state changes and automations in your Tempo timeline, with multi-key severity rules and human-readable titles via ${metadata.xxx} interpolation.

v1.0.0 · Home Assistant 2024.1+

Jellyfin

Jellyfin server events in Tempo's timeline with one-click actions to open the web UI, drill into items, or jump to admin.

v1.0.0 · Jellyfin 10.9 + Webhook plugin

Pi-hole

Pi-hole health and configuration changes in Tempo's timeline. Poll-driven from cron, native API, no plugins.

v1.0.0 · Pi-hole v6 (FTL HTTP API) / v5 with adjustments

Proxmox Backup Server

PBS notifications in your Tempo timeline. Jump into the dashboard, datastores, running tasks, or tail the task log over SSH — one click from each event.

v1.0.0 · PBS 3.2+ / PBS 3.3

Proxmox VE

Proxmox Virtual Environment cluster events in Tempo's timeline. Open the datacenter UI, jump to a specific node or VM, copy IDs for an incident ticket — one click per event.

v1.0.0 · Proxmox VE 8.1+

Synology

DSM notifications in your Tempo timeline, with one-click actions to jump into Storage Manager, Log Center, Security Advisor, and SSH.

v1.0.0 · DSM 7.0+ / DSM 7.1 / DSM 7.2

UniFi

Built-in

Bring UniFi Network alarms (client connect/disconnect, device lost contact) and UniFi Protect events (motion, smart-detect, doorbell) into your Tempo timeline. Built-in: ships with Tempo, no separate score to install.

v1.0.0 · Network 8.x / 9.x / 10.x / Protect 5.x

Vaultwarden

Vaultwarden auth events, admin actions, and liveness in Tempo's timeline. Poll- and log-driven, your admin token stays local.

v1.0.0 · Vaultwarden 1.32+

Contribute your own

Got a tool that should be in the catalog? Scores are JSON files — open a pull request at github.com/caereforge/tempo-scores and follow the CONTRIBUTING guide. The review rubric is public so you can self-check before submitting.

Not ready for a PR? Discuss the score idea first in the GitHub Discussions or the Tempo Discord. Both threads stay searchable so later contributors can build on your work.
